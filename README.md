# CrystalOps
### 可迁移的 AI 客服与运营工作台

**Plan × Skill × Tool × Eval，让客服从回答问题走向可观察、可配置、可评测的业务执行。**

CrystalOps 以水晶手串电商为示范场景，探索如何将客服流程拆分为可复用的模块：理解需求、规划任务、查询业务资料、调用工具、组织回复，再检查执行结果。

产品的核心设计是“业务插槽”：复用工作台框架，针对不同业务替换资料、调整能力、接入工具并配置评测标准。

[在线体验](https://haluwjm-lexie.github.io/crystalops-demo/) · [项目仓库](https://github.com/Haluwjm-Lexie/crystalops-demo) · [关于作者](https://github.com/Haluwjm-Lexie)

> 当前仓库为 GitHub Pages 公开互动演示版，使用浏览器内规则模型和模拟业务数据。无需登录、无需填写 API 密钥，未连接 DeepSeek，不产生真实交易。

## 为什么做 CrystalOps？

一次客服咨询，往往需要完成多项工作：

- 理解预算、用途、颜色、尺寸等需求。
- 查询商品、库存、优惠和售后政策。
- 根据业务规则计算价格、核对条件。
- 组织清晰的回复，避免编造信息或承诺效果。
- 记录处理过程，发现问题后调整并重新验证。

CrystalOps 将这些工作放进同一个工作台，让用户可以体验客服，让产品与运营人员可以检查回复依据、调整规则和验证效果。

## 核心设计：业务插槽与模块复用

不同业务需要不同的资料与规则，也有可以复用的处理结构。

| 模块 | 负责什么 | 迁移到新业务时需要适配什么 |
|---|---|---|
| **Plan / Planner** | 拆解任务，安排步骤与依赖 | 业务处理流程、可选能力与执行约束 |
| **Skill** | 理解需求、组织回复等业务能力 | 提示词、业务规则和输出要求 |
| **Tool** | 查询资料、计算金额、获取业务结果 | 数据来源、接口及输入输出结构 |
| **业务数据** | 提供商品、订单、政策等事实 | 新业务的资料与访问权限 |
| **Eval** | 检查结果是否符合要求 | 测试用例、参考条件与质量标准 |

例如，迁移到其他零售业务时，可以沿用计划、执行记录和评测入口，再适配对应的商品、优惠与售后规则。

**当前已实现水晶手串示范业务。跨行业迁移是设计方向，尚未完成第二个行业的验证，也不支持一键切换所有业务。**

## 可以体验什么？

| 模块 | 主要功能 |
|---|---|
| **作品概览** | 了解项目定位、业务场景和体验入口 |
| **客服体验** | 输入选购需求，进行咨询与连续追问 |
| **演示商品** | 查看商品款式、规格、手围与演示售价 |
| **执行工作台** | 查看客服回复及实际执行证据 |
| **Planner** | 单独预览任务计划、能力选择与步骤依赖 |
| **Skill 实验室** | 查看业务能力，编辑个人副本并进行规则实验 |
| **Tool 测试** | 输入参数，查看演示工具的实际计算或查询结果 |
| **Eval 评测** | 运行预设用例，检查回复是否符合业务要求 |
| **运行与评分** | 查看当前浏览器中的运行记录，进行人工评分 |
| **模型配置** | 了解当前演示模型、运行方式与能力边界 |

### Planner 与执行工作台有什么区别？

- **Planner**：查看“准备怎样处理”，预览计划时不执行业务工具。
- **执行工作台**：查看“实际怎样处理”，包括能力调用、工具结果与审核记录。

计划和执行结果分开展示，方便理解流程，也便于排查问题。

## 试一次完整流程

输入：

> 预算200元，想买粉色手串，自己戴，手围14厘米。请推荐一款，说明尺寸是否适合，以及优惠后多少钱。

工作台会根据当前规则：

1. 提取预算、颜色、用途和手围等条件。
2. 生成任务计划。
3. 查询演示商品，核对规格与尺寸。
4. 根据演示优惠规则计算金额。
5. 组织回复并执行检查。
6. 展示推荐结果与执行证据。

随后可以继续追问：

> 如果买两条呢？

也可以进入 Skill 实验室调整结构化回复规则，再对比同一问题的表现。

## 如何检查与改进回复？

CrystalOps 提供两种互补的检查方式：

- **自动 Eval**：根据预设用例和检查规则，验证商品、金额、追问及安全边界等表现。
- **人工评分**：由体验者对具体运行结果进行评价，补充自动检查难以覆盖的判断。

Skill 实验室支持查看和编辑个人能力副本，并保留版本与恢复入口。实验只影响当前浏览器中的个人体验，不会修改其他访客的配置。

## 当前演示版的能力边界

### 可以直接体验

- 浏览演示商品并进行客服咨询。
- 运行浏览器内的业务查询和优惠计算。
- 查看计划与执行证据。
- 调整结构化回复规则，进行单项测试与评测。
- 保存个人实验配置、运行记录和评分。

### 需要了解的限制

- **模型**：此版本使用规则模型，未连接 DeepSeek 或其他远程大模型。
- **Prompt**：自由 Prompt 可以编辑保存，但规则模型不会解释自由 Prompt；结构化回复规则可直接实验。
- **数据**：商品、库存、优惠、订单与物流均为模拟资料。
- **交易**：不下单、不支付，不连接真实电商或物流系统。
- **存储**：个人配置与运行记录保存在当前浏览器，不跨设备同步；清除浏览器数据可能删除这些记录。
- **迁移**：接入新业务仍需要资料整理、代码或接口适配，以及对应的评测验证。

水晶寓意仅用于文化象征与祝福表达，不承诺招财、脱单、治疗或其他实际功效。
